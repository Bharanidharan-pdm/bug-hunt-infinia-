Event Rules

BUG HUNT — Find the Bug. Fix the Code. Win the Hunt.

  1. Each team must contain exactly 2 members.
  2. One team uses one common login account shared by both members.
  3. Teams must solve debugging questions within the given time.
  4. Questions are created and controlled by the event Admin.
  5. Scores are calculated automatically (backend is the source of truth).
  6. Hidden test cases are not visible to participants.
  7. Teams cannot access other teams' data.
  8. Leaderboard is available only to event organizers.
  9. Teams must follow the event's competition rules.
  10. Admin can disable teams for rule violations.
